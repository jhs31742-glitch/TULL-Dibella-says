# CP008 공통 효과 적용과 타락 패시브

## 확정 결정

| 항목 | 규칙 |
|---|---|
| 순결의 직접 파괴마법 피해 | +50% |
| 타락의 직접 파괴마법 피해 | 최종 +30%. 중간 단계는 0/4/9/13/17/21/26/30%로 배분한 개발안 |
| 타락의 화술 숙련도 | 최종 +50. 중간 단계는 0/7/14/21/29/36/43/50 |
| 적용 조건 | 기존 타락 단계 0/100/250/500/900/1400/2000/3000 |
| 세이브 전환 | 개발자 모드·전투 오라 초기화. 하드코어는 불러온 세이브의 기록만 적용 |

## 구현 및 검증 범위

- 화술은 TDS 소유의 상시 능력으로 추가한다. 기존 ESPFE 레코드는 유지하며 화술 능력과 효과를 각각 7개 추가한다. 현재 타락 단계에 해당하는 화술 능력 하나만 선택한다.
- 직접 파괴마법 피해는 계산과 출처 필터까지 구현됐다. 게임 엔진 호출점 및 POT 동시 활성화는 미연결이다.
- 일반·가상 통계가 같은 장비·성장·순결·자원·근접 경로를 사용하도록 연결했다. 엔진 저장 차단 플래그의 수동·자동·빠른·콘솔 저장 차단 범위는 별도 검증한다.
- SE 1.5.97이 우선 대상이다. POT의 AE 1.6.1170 SpellsLearned 패치는 해당 이벤트 수정을 위한 것으로, 피해 훅 ABI 검증에 갈음하지 않는다.
- 개발자 모드 하드코어 실효과, 대상별 피해 내성, 원거리 및 직접 마법 처리, 교감·역전 타락도 수치 확정이 남았다. 하드코어 매지카 0은 기존 후순위 OPEN이다.

## 배포 경계

`SOURCE=PARTIAL / DEPLOY=HOLD_INCOMPLETE / RUNTIME=NOT_RUN / LOCK=NO`

기존 설치 후보는 0.1.11.8이다. 소스 스냅샷을 비공개 저장소에 올리는 작업과 게임 QA 후보 배포는 별도 판정한다.
