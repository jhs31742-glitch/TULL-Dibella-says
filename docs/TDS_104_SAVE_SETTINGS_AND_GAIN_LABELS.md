# TDS 1.0.4 — 세이브별 설정 저장·복원 및 획득량 표시 수정

## 원인과 변경
기존 단축키 변경은 메모리만 갱신하고 INI/co-save에 기록하지 않았다. 오라와 HUD는 세이브 혼입 방지를 위해 로드마다 초기화했으나 해당 세이브의 값을 복원하지 않았다.
별도 SET1 v1 레코드(32바이트)를 추가했다. 단축키와 Shift/Ctrl/Alt, HUD ON/OFF·방향·X/Y 위치·크기·타입, 오라 ON/OFF를 해당 게임 세이브의 SKSE co-save에 저장한다. 기존 성장·장비·하드코어 레코드의 형식은 변경하지 않는다.
로드 시 기존 상태·HUD 뷰를 먼저 제거하고 INI/기본값으로 초기화한 다음, 해당 세이브의 SET1을 복원한다. 새 게임·구형/누락/손상/중복/미지원 버전 기록은 기본값을 사용하고 직전 세이브 값을 빌려오지 않는다. 단축키는 기본 INI를 읽되 UI 변경으로 전역 INI를 덮어쓰지 않는다.
DEV 세션은 저장 콜백 초반에 반환하며 가상 통계와 이 세션에서 바꾼 설정을 co-save에 쓰지 않는다. 일반 세이브를 로드하면 그 세이브의 설정을 다시 복원한다. 실제 세이브 파일을 에이전트가 열거나 수정하지 않았다.

## 타락도 표시
획득 수식과 게임 수치는 변경하지 않았다. 관계0회 첫 자위+질 통계 증가의 실제 타락도는 기본3+추가4+질1=8이다. 자위 기본은 관계0회에서 순번1~12에 따라3~36이며 공통 자위 추가는4~48이다. +4를 순결 전용 보너스로 오표기하지 않는다.
통계 표에 현재 횟수/다음 만족도/다음 타락도를 표시하고, 하단을 최근 장면 실제 획득으로 구분한다. 자위 항목에 커서를 올리면 관계0회 기본·추가 기여 설명이 나온다.
가장 최근 자위 정산에는 기본/추가/그 외 통계·보정/합계 분해를 한 줄로 표시한다. 예시는3+4+1=8이며 타락도 양수는 밝은 핑크색, 음수는 빨간색이다. 이전 두 기록은 호버로 세부 구성을 확인한다. 기존 저장 기록은 상세 기여가 저장돼 있지 않으면 합계만 표시하며 값을 추정해 채우지 않는다. 한국어·영어 문자열을 함께 반영했다.

## 사용자 실게임 확인 질문3개
1. 일반 모드에서 설정→저장→동일 세이브 재로드/게임 재실행 후 단축키·HUD·오라가 복원되는가?
2. A와 B에 다른 설정을 저장한 뒤 A→B→A에서 섞이지 않고, DEV 변경 후 일반 세이브로 돌아오면 원래 설정이 복원되는가?
3. 통계 팝업의 다음1회 예상과 최근 실제획득이 구분되며, 자위 첫 장면의 +8 기여가 이해 가능한가?

교훈: 세션 초기화는 저장별 복원 구현을 대체하지 않는다. UI가 변경값을 표시하거나 메모리 상태가 바뀌는 것과 지속 저장 성공을 구별해 검증한다.
